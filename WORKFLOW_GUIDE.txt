💡 TIPS & BEST PRACTICES:
==========================

IMAGE NAMING:
-------------
Use consistent naming in GitHub:
✅ lowercase-with-hyphens.jpg
✅ opalite-bracelet.jpg
✅ amethyst-necklace.jpg

❌ Opalite Bracelet.jpg (spaces = bad!)
❌ OpaliteBracelet.JPG (inconsistent case)

IMAGE SIZING:
-------------
Before uploading to GitHub:
- Resize to 800x800 pixels (square)
- Keep under 500KB per image
- Use JPG for photos
- Compress at: tinypng.com

FOLDER STRUCTURE:
-----------------
GitHub repo:
```
repo/
├── images/
│   ├── opalite-bracelet.jpg
│   ├── amethyst-necklace.jpg
│   ├── tourmaline-necklace.jpg
│   └── ...
├── products-data.json
├── index.html
└── ...
```

📝 IMAGE URL FORMATS:
======================

CORRECT FORMATS:
✅ images/opalite-bracelet.jpg
✅ images/products/amethyst.jpg
✅ images/new-arrivals/tourmaline.jpg

WRONG FORMATS:
❌ /images/opalite.jpg (leading slash)
❌ images\opalite.jpg (backslash - Windows)
❌ images/opalite bracelet.jpg (space)
❌ C:\Users\photos\opalite.jpg (local path)

🔍 TROUBLESHOOTING:
===================

PROBLEM: Preview button shows "Could not load image"
-----------------------------------------------------
CAUSES:
- Image not uploaded to GitHub yet
- Wrong image path (typo)
- Image in wrong folder
- Case mismatch (Image.jpg vs image.jpg)

FIX:
1. Check GitHub - is image there?
2. Check exact filename (case-sensitive!)
3. Try full URL: https://your-site.pages.dev/images/filename.jpg
4. If 404, upload image first

PROBLEM: Products added but no download button
-----------------------------------------------
FIX: Download button appears automatically after adding first product

PROBLEM: JSON downloaded but website still shows old products
--------------------------------------------------------------
FIX:
1. Make sure you uploaded NEW JSON to GitHub
2. Check GitHub file has your products
3. Wait 2 minutes for deployment
4. Hard refresh (Ctrl + Shift + R)
