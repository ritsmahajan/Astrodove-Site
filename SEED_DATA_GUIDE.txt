🎨 CUSTOMIZING SEED PRODUCTS:
==============================

Want to change the seed products?

Edit seed-data.js:

```javascript
{
    name: "Your Product Name",
    price: "2500",
    category: "healing", // healing, love, protection, abundance, clarity, chakra
    badge: "NEW ARRIVAL", // or "POPULAR", "BESTSELLER", "LIMITED", ""
    description: "Your product description here...",
    benefits: ["Benefit 1", "Benefit 2", "Benefit 3"],
    image: "your-image-data-here"
}
```

Save and redeploy!

📸 ADDING REAL IMAGES TO SEED DATA:
====================================

OPTION 1: Use Real Crystal Images
----------------------------------
1. Find/take photos of your crystals
2. Convert to base64:
   - Go to: https://base64.guru/converter/encode/image
   - Upload image
   - Copy base64 string
3. Replace in seed-data.js:
   image: "data:image/jpeg;base64,YOUR-BASE64-HERE"

OPTION 2: Use URLs
------------------
If you have images hosted somewhere:
image: "https://your-domain.com/crystal.jpg"

OPTION 3: Keep Emoji Placeholders
----------------------------------
Current emoji icons work fine!
Replace with real images when ready.
